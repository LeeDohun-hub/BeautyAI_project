## 2. 学んだこと・分かったこと

・Docker Compose により、バックエンドとフロントエンドを一括で実行できることを確認
・ポート競合は、ローカル DB や既存の実行サービスが原因で発生する可能性がある
・Yahoo Japan Search は海外からのアカウント作成試行として判定され、API 利用が難しい
・外部商品 API は認証エラーや rate limit があるため、内部 DB の推薦機能と組み合わせる構成が安定する
・商品推薦では、プラットフォーム適合度、評価、レビュー数、キーワード適合度をあわせて考慮する必要がある
・マツキヨのようにデータが不足しているプラットフォームは、検索リンク方式または別途カタログ補強が必要
