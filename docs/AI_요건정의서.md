# BeautyAI 요건정의서

## 1. 문서 정보

| 항목 | 내용 |
|---|---|
| 시스템명 | BeautyAI (서비스명 **YoPalette**) |
| 대상 | 사진 한 장으로 피부·퍼스널컬러·네일을 분석하고 상품을 추천하는 서비스 |
| 목적 | 분석 결과를 근거로 살 수 있는 상품까지 연결하고, 그 결과를 BeautyWEB 계정·장바구니로 넘긴다. |
| 작성 기준 | 2026-08-10 기준 실제 구현 코드 |
| 이전 판 | 2026-06-29. 당시에는 얼굴·바디 피부 분석과 추천·상담뿐이었다. **퍼스널컬러·네일·가상성형·다국어·웹 연동이 추가되어 전면 개정한다.** |

## 2. 서비스 범위

BeautyAI 는 다섯 개의 독립 모듈로 구성된다.

| 모듈 | 하는 일 |
|---|---|
| 홈 | 모듈 선택, 웹 계정 연동 상태 표시 |
| 피부 케어 분석 | 얼굴·바디 사진 분석 → 성분·상품 추천 → 결과지 |
| 퍼스널컬러 | 얼굴 사진 → 시즌 판정 → 팔레트·메이크업 → 아이템 매칭 → 결과지 |
| 네일·페디 디자인 | 손·발 사진 → 네일 검출·발색 미리보기 → 비슷한 디자인·상품 |
| 가상 성형 | 얼굴 비율 분석 → 목표별 미리보기 → 상담용 리포트 |

## 3. 사용자

| 사용자 | 설명 | 주요 행위 |
|---|---|---|
| 익명 사용자 | 로그인 없이 이용 | 설문 → 사진 분석 → 추천 확인 |
| 웹 연동 사용자 | BeautyWEB 계정으로 들어온 사용자 | 프로필 프리필, 저장된 퍼스널컬러 사용, 결과지 QR → 웹 장바구니 |
| 일본어 사용자 | 화면 언어를 일본어로 쓰는 사용자 | 위와 동일. **모든 안내·판정문이 일본어여야 한다** |
| 운영자 | 서비스 지표를 보는 사용자 | 통계 조회 |

## 4. 기능 요구사항

### 4.1 설문

- 나이·성별·인종·피부타입·민감도·고민을 받는다.
- 개인정보 활용 동의 전에는 다음 단계로 넘어갈 수 없다.
- 웹 계정으로 들어오면 프로필로 설문을 미리 채운다.

### 4.2 얼굴 피부 분석

- 사진 1장 이상으로 6개 항목(트러블·모공·주름·홍조·색소침착·유분)을 0~100 으로 낸다.
- 촬영 품질에 따른 신뢰도 안내를 함께 낸다(얼굴 미검출·조명 등).
- 여러 장을 넣으면 평균으로 흔들림을 줄인다.
- ⚠ 6개 항목은 서로 완전히 독립되지 않는다. **3그룹·3구간 표시**를 원칙으로 하고, 소수점까지 단정적으로 보여주지 않는다.

### 4.3 바디·피부질환 선별

- 몸 사진에서 피부질환 가능성을 선별한다(확정 진단이 아님을 반드시 명시).
- 악성 의심은 제품 추천 대신 진료 안내를 우선한다.
- 자극 가능성이 있는 성분(레티놀·AHA/BHA)은 제외한다.

### 4.4 영유아

- 영유아는 성인 제품으로 폴백하지 않는다. **성분 우선 안내**로 대체한다.
- 향료 게이트는 다국어로 검사한다. 일본어 향 표현이 빠지면 아동에게 향료가 새어 나간다.

### 4.5 퍼스널컬러

- 얼굴 사진으로 시즌 타입을 판정하고 판정 근거·경계 안내를 낸다.
- 팔레트·메이크업 컬러·스타일 무드를 제시한다.
- 웹에 저장된 퍼스널컬러가 있으면 촬영 없이 바로 쓸 수 있다.
  - 이때 `metrics` 가 비므로 **촬영 품질 배지를 숨긴다**(0% 로 보이면 오해를 준다).
- 얼굴형 분석을 함께 제공한다.

### 4.6 아이템 매칭 (상품 추천)

- 판정 결과에 맞는 상품을 **카테고리 컬럼**으로 보여준다.

| 대상 | 컬럼 |
|---|---|
| 퍼스널컬러(여성) | 립 · 블러셔 · 아이 · 베이스 · 네일 |
| 퍼스널컬러(남성) | 베이스 · 브로우 · 컨실러 · 립밤 |
| 피부(얼굴) | 클렌저 · 토너 · 세럼 · 보습 · 선크림 |
| 피부(바디) | 바디 세정 · 바디 보습 |

- 지역(한국/일본)과 구매 플랫폼(올리브영·아마존·라쿠텐·마츠키요 등)으로 거를 수 있다.
- 구매 링크가 없는 카드는 내보내지 않는다.
- 가격은 표시하지 않는다. 카드 하나에 판매처가 여럿이라 어느 값을 써도 최소 하나는 틀린다.

### 4.7 네일·페디

- 손·발 사진에서 네일 영역을 검출하고 색을 추출한다.
- 선택한 색으로 발색 미리보기를 만든다(타원 근사이므로 실제와 다를 수 있음을 명시).
- 비슷한 디자인을 검색하고, 그 색으로 살 수 있는 상품을 보여준다.

### 4.8 가상 성형

- 얼굴 비율을 분석하고 목표별(계란형·V라인·동안형 등) 미리보기를 만든다.
- 잡티·점은 자동 제거가 아니라 **사용자가 고른 위치만** 처리한다.
- 결과는 상담용 리포트이며 수술 결과 예측이 아님을 명시한다.

### 4.9 AI 상담

- 피부 고민·성분·루틴 질문에 답한다.
- 근거가 있으면 참고 근거를 함께 표시한다.
- 카탈로그 질문은 **LLM 이 아니라 DB 가** 답한다.

| 질문 유형 | 처리 |
|---|---|
| "OO 라는 상품 있나요?" | 카탈로그 조회. 없으면 없다고 답한다(지어내지 않는다) |
| "매장에 없대요, 다른 추천은?" | 재고를 아는 척하지 않고, 피부 점수 기반 같은 성분 계열 상품을 제시 |
| 그 외 상담 | 근거 검색 후 LLM 이 답변 작성. 실패하면 지식베이스로 폴백 |

- 답변 작성 중임을 화면에 글자로 알린다.
- 범위 밖 질문은 억지로 답하지 않는다.

### 4.10 결과지

- 분석 결과와 담은 상품을 인쇄용 결과지로 만든다.
- 결과지 QR 로 BeautyWEB 장바구니에 담을 수 있다.

### 4.11 웹 연동

| 방향 | 요구사항 |
|---|---|
| WEB → AI | 120초 1회용 핸드오프 티켓으로 로그인한다. 액세스 토큰을 그대로 받지 않는다. AI 자체 세션은 12시간. |
| AI → WEB | 결과지 QR 에는 1회용 코드만 싣는다. 상품 목록은 서버끼리 주고받는다. |

### 4.12 다국어 (한국어 / 일본어)

- 화면 문구는 프론트 사전으로 옮긴다.
- **수치·이름이 끼어 조립되는 문장**(판정문·요약문·상담 답변)은 프론트 사전으로 못 옮기므로 **서버가 한국어·일본어 두 벌을 만들어 내려보낸다**.
- 번역본이 없으면 그 문단을 생략한다. 일본어 화면에 한국어를 섞지 않는다.

### 4.13 개인정보

- 내 데이터(분석·설문·추천·상담 이력) 삭제 기능을 제공한다.
- 업로드 파일명은 저장하지 않는다(확장자만 남긴다).

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 응답 시간 | 얼굴 추천은 CPU 추론 + 라이브 검색이 겹쳐도 실용 범위를 유지한다. 성분 인덱스는 캐시하고, 랭킹 루프에서 관계 로딩을 하지 않는다. |
| 반응형 | 360px(갤럭시)에서 상품추천이 한 화면에 여러 개 보이고, 어느 카테고리인지 항상 알 수 있어야 한다. |
| 접근성 | 터치 기기에서 버튼·칩의 탭 타깃 하한 44px 를 지킨다. 색은 보조 신호이고 이름표는 항상 글자로 남긴다. |
| 안전성 | 분석 결과는 참고용이며 확정 진단이 아님을 화면에 명시한다. 악성 의심은 진료를 우선 안내한다. |
| 데이터 | 모델 파일·RAG 코퍼스가 없으면 해당 기능은 `feature_available=false` 로 꺼진다. 서비스 전체가 죽지 않는다. |
| 재현성 | 조립형 한국어 문장은 목록으로 고정해, 새로 생기면 테스트가 잡는다. |

## 6. 외부 연동

| 대상 | 용도 | 비고 |
|---|---|---|
| BeautyWEB | 계정 핸드오프, 장바구니 담기, 카탈로그 공급 | `JWT_SECRET` 공유 |
| OpenAI | 상담 답변 생성 | 키가 없으면 지식베이스 폴백 |
| 라쿠텐 API | 일본 상품 검색 | 호출 빈도 제한 주의 |
| 올리브영 | 상품 카탈로그 | 국내몰은 봇 차단이 있어 브라우저 경유 수집 |
| 아마존 | 상품 링크 | 검증된 ASIN 직링크만 사용 |

## 7. 제외 범위

- 의학적 진단·처방
- 실제 결제(BeautyWEB 이 담당)
- 시술·수술 결과 보장
- 사용자 사진의 외부 공유
