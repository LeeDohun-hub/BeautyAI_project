# 의료광고 — 작업 전제 (가정)

> ## ⚠️ 이 문서는 법률 의견이 아닙니다
>
> 실제 법무 회신은 **아직 받지 않았습니다.** 회신을 기다리는 동안 개발이 멈추지 않도록,
> 개발팀이 **스스로 정한 가정**을 적어 둔 것입니다. 변호사·심의기관이 검토한 내용이
> 아니며, 법적 효력이나 근거로 쓸 수 없습니다.
>
> 실제 회신이 오면 이 문서는 **폐기**하고, 아래 §4 의 대조표로 무엇이 달라지는지 확인합니다.
>
> 요청서 원본: `docs/medical_ad_legal_review_request.md`
> 작성 2026-08-04 · 작성 주체: 개발팀 · 상태: **가정, 미확인**

---

## 1. 왜 가정을 세우는가

회신까지 기능 개발을 전부 멈추면 그동안 아무것도 못 만듭니다. 반대로 아무 전제 없이
만들면 회신 후에 갈아엎게 됩니다.

그래서 **가장 빡빡한 해석**을 전제로 잡습니다. 실제 회신이 이보다 느슨하면 제약을 풀면
되지만, 반대 방향(느슨하게 잡았다가 조여야 하는 경우)은 이미 만든 것을 되돌려야 합니다.
되돌리기 비용이 비대칭이므로 보수적으로 갑니다.

## 2. 전제 (쟁점별)

### 전제 1 — 병원 연결이 붙는 순간 의료광고로 본다

요청서 §2 쟁점1의 (가)~(라) 중 **(나) 이상, 즉 병원 상세·예약 링크를 제공하는 순간**
운영사가 의료광고를 매개하는 것으로 본다.

→ **개발 규칙**: 병원 연결 기능은 회신 전까지 만들지 않는다. 데이터 모델·화면 자리
  잡기까지도 하지 않는다(만들어 두면 "켜기만 하면 된다"는 압력이 생긴다).

### 전제 2 — 사전심의 대상이며, 신청 주체는 제휴 병원이다

운영사는 의료기관이 아니므로 직접 신청 주체가 될 수 없고, 제휴 병원이 자기 광고로
심의를 받아야 한다고 본다.

→ **개발 규칙**: 병원 연결 화면은 **병원별로 켜고 끌 수 있어야** 한다. 심의를 통과한
  병원만 노출하는 구조여야 하므로, 전체 일괄 노출 설계는 처음부터 배제한다.

### 전제 3 — 현재 고지 문구는 부족하다고 본다

지금 문구는 "시술 전후 사진이 아니다 / 특정 의료기관을 광고하지 않는다"까지만 말한다.
**효과를 보장하지 않는다**, **개인차가 있다**가 빠져 있다.

→ **개발 규칙**: 아래 두 문장을 추가한다. 회신이 "불필요"라고 하면 빼면 되고,
  넣어서 손해 볼 것이 없다.
  - "실제 결과는 개인에 따라 다르며, 이 이미지는 결과를 보장하지 않습니다."
  - "이 서비스는 의료기관이 아니며, 진단·치료·시술을 제공하지 않습니다."

### 전제 4 — 일본에서는 비포/애프터로 본다 ★가장 제약이 큼

일본 医療広告ガイドライン 이 요구하는 병기 항목(시술 내용·비용·주요 위험/부작용)을
이 기능은 **원리적으로 채울 수 없다.** 특정 시술과 연결돼 있지 않아 "무엇의 비용"인지
쓸 수가 없기 때문이다.

→ **개발 규칙**: 병원 연결이 붙는 시점에, **일본 로케일에서는 비포/애프터 병렬 표시를
  끈다.** 원본과 변형본을 나란히 놓지 않고 변형본만 보여주거나, 일본에서는 미리보기
  자체를 비활성화한다. 어느 쪽인지는 회신으로 정한다.
  ⚠ **병원 연결 전까지는 현행 유지.** 지금은 의료광고 주체가 아니라는 해석이 성립한다.

### 전제 5 — 얼굴 사진은 생체정보에 준해 취급한다

법적으로 생체정보인지와 무관하게, 그렇게 다루면 안전한 쪽이다.

→ **개발 규칙**:
  - 원본 사진 미저장 — **이미 그렇다**
  - 파일명 미저장 — **이미 그렇다**(확장자만)
  - 사용자 삭제 수단 — **이미 있다**(`DELETE /api/me/data` + 화면)
  - 업로드 전 동의 고지 — **없다. 추가 대상**
  - 보관 기간 자동 만료 — 기간이 정해져야 하므로 보류

### 전제 6 — 미성년자 연령 확인이 필요하다

→ **개발 규칙**: 성형 모듈 진입 시 연령 확인을 넣는다. 다만 **연령 확인 방식**(자기신고 /
  본인인증 / 법정대리인 동의)은 회신이 정해야 하므로, 우선 자기신고 + 안내로 시작한다.

## 3. 지금 할 수 있는 것 / 회신을 기다리는 것

| 항목 | 회신 없이 가능? | 근거 |
|---|---|---|
| 고지 문구 강화(전제 3) | **가능** | 더 붙이는 것은 위험을 늘리지 않는다 |
| 업로드 동의 고지(전제 5) | **가능** | 같은 이유 |
| 연령 확인(전제 6) | **가능** | 자기신고 수준이면 되돌리기 쉽다 |
| 일본 비포/애프터 제어(전제 4) | 준비만 | 끄는 스위치는 만들되 켜진 채로 둔다 |
| 병원 연결(전제 1·2) | **불가** | 만드는 순간 검토 대상이 바뀐다 |
| 비용 범위 표시 | **불가** | 의료광고 판정의 핵심 요소 |
| 보관 기간 자동 만료 | **불가** | 기간이 정책이다 |

---

## 4. 회신이 오면 확인할 것 (대조표)

회신을 받으면 아래를 하나씩 대조해 이 문서를 폐기한다.

| 전제 | 회신이 더 느슨하면 | 회신이 더 빡빡하면 |
|---|---|---|
| 1. 광고 해당 시점 | 병원 연결 착수 | 변경 없음(이미 안 만듦) |
| 2. 심의 주체 | 일괄 노출 허용 | 변경 없음(병원별 토글 유지) |
| 3. 고지 문구 | 문장 제거 | 지정 문구로 교체 |
| 4. 일본 비포/애프터 | 스위치 제거 | 스위치를 켜서 JP 제한 |
| 5. 사진 취급 | 동의 고지 간소화 | 별도 동의 절차·암호화 |
| 6. 미성년자 | 연령 확인 제거 | 본인인증·법정대리인 동의 |

---

## 5. 이 문서로 정당화되지 않는 것

- 실제 법적 안전성. 가정은 검증이 아니다.
- 대외 설명. "법무 검토를 거쳤다"고 말할 근거가 되지 않는다.
- 병원·투자자·심사기관 제출. 이 문서는 **내부 개발용**이다.
