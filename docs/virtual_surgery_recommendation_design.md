# 가상 성형 추천 시스템 설계안

작성일: 2026-08-03  
범위: 제품/UX/기능 설계 문서  
주의: 본 문서는 코드 변경 없이 기획 및 설계 방향을 정리한 문서입니다.

## 1. 제품 포지션

가상 성형 추천 시스템은 사용자의 얼굴 사진과 선호 이미지를 바탕으로 얼굴 비율을 분석하고, 상담 전 참고할 수 있는 개선 방향과 AI 미리보기를 제공하는 기능이다.

이 기능은 의료 진단이나 수술 확정 추천이 아니라, 다음 목적을 가진다.

- 사용자가 원하는 변화 방향을 구체화한다.
- 얼굴 비율과 인상 변화 가능성을 시각적으로 이해하게 한다.
- 병원 상담 시 사용할 수 있는 상담용 리포트를 생성한다.
- 수술/시술 후보를 단정하지 않고, 상담 후보로 정리한다.

따라서 서비스 내 표현은 "성형 진단", "수술 필요", "결과 예측"이 아니라 "사진 기준 추정", "상담 후보", "참고용 AI 미리보기" 중심으로 설계해야 한다.

## 2. 전체 사용자 흐름

권장 단계는 5단계다.

1. 기본정보 및 목표 설정
2. 사진 업로드 및 품질 확인
3. 얼굴 비율 분석
4. 개선 방향 카드 선택
5. 상담용 결과지 출력

현재 화면의 단계 구조는 유지하되, 일부 명칭은 더 안전하고 전문적인 표현으로 바꾸는 것을 권장한다.

| 현재 명칭 | 권장 명칭 |
| --- | --- |
| 개인정보 입력 | 기본정보 및 목표 설정 |
| AI 성형 분석 | 사진 업로드 및 AI 분석 |
| 얼굴형 분석결과 | 얼굴 비율 분석 |
| 개선 얼굴형 선택 | 개선 방향 선택 |
| 결과지 출력 | 상담용 리포트 출력 |

## 3. 1단계: 기본정보 및 목표 설정

사용자에게 단순 개인정보만 받는 것이 아니라, 실제 상담에 필요한 목표와 제약 조건을 함께 받는다.

### 입력 항목

- 성별
- 연령대
- 가장 개선하고 싶은 부위
- 원하는 변화 이미지
- 선호 변화 강도
- 예산 범위
- 회복 가능 기간
- 수술/비수술 선호도
- 과거 시술/수술 여부
- 알레르기 또는 특이 질환 여부
- 사진 분석 및 AI 미리보기 처리 동의

### 개선 부위 선택

복수 선택을 허용하되, 1순위 개선 부위를 별도로 받는 것이 좋다.

추천 선택지:

- 윤곽/얼굴형
- 턱끝/하관
- 광대 폭
- 코 라인
- 눈/눈매
- 이마/중안부
- 입술/입 주변
- 좌우 비대칭
- 피부결/잡티
- 전체 인상 균형

### 원하는 변화 이미지

사용자는 구체적인 시술명보다 원하는 인상을 더 잘 선택한다. 따라서 변화 이미지는 시술명이 아니라 인상 중심으로 구성한다.

추천 선택지:

- 자연스러운 변화
- 또렷하고 세련된 인상
- 부드러운 동안 이미지
- V라인처럼 갸름한 느낌
- 좌우 균형 개선
- 코 라인 정돈
- 피부결까지 깨끗한 느낌
- 사진에서 더 선명한 인상

## 4. 2단계: 사진 업로드 및 품질 확인

### 권장 사진

MVP에서는 정면 사진 1장으로 시작할 수 있다. 다만 전문성을 높이려면 다음 구성을 권장한다.

- 정면
- 좌측 45도
- 우측 45도
- 측면

### 품질 체크

분석 전에 사진 품질을 확인해야 한다.

- 얼굴이 정면을 향하는지
- 조명이 너무 어둡지 않은지
- 얼굴이 가려지지 않았는지
- 과도한 필터나 보정이 없는지
- 눈, 코, 입, 턱선이 충분히 보이는지
- 해상도가 너무 낮지 않은지

품질이 낮은 경우 바로 분석하지 않고 재촬영 안내를 보여준다.

## 5. 3단계: 얼굴 비율 분석

분석 결과는 단정적인 평가가 아니라 사진 기준의 추정 결과로 표현한다.

### 분석 항목

- 얼굴 전체 비율
- 상안부, 중안부, 하안부 비율
- 좌우 대칭 정도
- 턱끝 위치와 하관 길이
- 광대 폭과 얼굴 외곽선
- 코 라인과 중안부 균형
- 입 주변과 턱선 연결
- 피부결/잡티/톤 균일도

### 결과 표현 예시

권장 표현:

- "정면 사진 기준 하안부가 상대적으로 길게 인식됩니다."
- "턱끝과 입 주변 밸런스를 조정하면 인상 변화가 크게 느껴질 수 있습니다."
- "광대 폭보다 턱선 정리가 우선순위로 보입니다."
- "사진 조명 영향으로 피부결 분석 정확도가 낮을 수 있습니다."

피해야 할 표현:

- "턱 수술이 필요합니다."
- "코 성형을 해야 합니다."
- "비대칭이 심합니다."
- "이 시술을 받으면 예뻐집니다."

## 6. 4단계: 개선 방향 카드 선택

AI가 3개에서 5개의 개선 방향 카드를 생성한다. 카드는 수술명 중심이 아니라 목표 이미지 중심으로 구성한다.

### 카드 예시

#### Natural Balance

- 목표: 거의 티 나지 않는 자연스러운 비율 보정
- 변화 강도: 낮음
- 주요 변화 부위: 턱선, 좌우 균형, 피부결
- 적합 사용자: 자연스러운 변화를 원하는 사용자
- 상담 후보: 피부 관리, 리프팅, 소량 필러, 보톡스 등

#### Soft Youthful

- 목표: 부드럽고 어려 보이는 인상
- 변화 강도: 낮음~중간
- 주요 변화 부위: 중안부, 입 주변, 피부결
- 적합 사용자: 강한 변화보다 부드러운 인상을 원하는 사용자
- 상담 후보: 볼륨 보정, 피부 시술, 리프팅 계열

#### Defined V-Line

- 목표: 턱선과 하관이 정리된 인상
- 변화 강도: 중간~높음
- 주요 변화 부위: 턱끝, 하관, 얼굴 외곽선
- 적합 사용자: 얼굴형 변화를 가장 크게 원하는 사용자
- 상담 후보: 윤곽 상담, 턱끝 상담, 보톡스, 리프팅

#### Refined Nose Line

- 목표: 코와 중안부 중심의 세련된 인상
- 변화 강도: 중간
- 주요 변화 부위: 콧대, 코끝, 중안부 균형
- 적합 사용자: 얼굴 중심부 인상 변화를 원하는 사용자
- 상담 후보: 코 필러, 코 성형 상담, 중안부 밸런스 상담

#### Symmetry Focus

- 목표: 좌우 균형 중심의 정돈된 인상
- 변화 강도: 낮음~중간
- 주요 변화 부위: 눈높이, 턱선, 입꼬리, 얼굴 외곽선
- 적합 사용자: 사진에서 비대칭이 신경 쓰이는 사용자
- 상담 후보: 보톡스, 필러, 교정 상담, 리프팅

### 카드 구성 요소

각 카드에는 다음 정보를 포함한다.

- 카드명
- 목표 인상
- 변화 강도
- 주요 개선 부위
- 어울리는 이유
- 예상 상담 후보
- 주의할 점
- AI 미리보기 이미지

### 변화 강도 선택

비율조정 단계는 MVP에서 제외한다. 턱끝, 광대, 코 높이 같은 항목을 사용자가 직접 조절하면 실제 의학적 가능성과 다른 기대가 생길 수 있고, 서비스가 전문 상담 도구보다 이미지 편집 도구처럼 느껴질 수 있다.

대신 각 개선 방향 카드 안에서 변화 강도만 간단히 선택하게 한다.

- 자연스럽게
- 적당히 변화
- 또렷하게

이 정도의 선택은 사용자가 이해하기 쉽고, 실제 수술 수치처럼 보이지 않아 의료적 오해를 줄일 수 있다.

## 7. 5단계: 상담용 결과지 출력

결과지는 사용자가 병원 상담 시 참고할 수 있는 형태로 제공한다.

### 결과지 포함 항목

- 사용자 기본정보 요약
- 선택한 목표 이미지
- 선택한 개선 방향 카드
- Before 이미지
- AI Preview 이미지
- 얼굴 비율 분석 요약
- 개선 우선순위 1~3위
- 비수술 상담 후보
- 수술 상담 후보
- 예상 비용 범위
- 예상 회복 기간 범위
- 시술 난이도
- 리스크 및 주의사항
- 상담 시 의사에게 물어볼 질문
- AI 미리보기 고지문

### 비용 표현 방식

비용은 확정 견적이 아니라 범위로 제공한다.

예시:

- 낮음: 피부 관리, 보톡스, 일부 필러 중심
- 중간: 리프팅, 필러 조합, 코/입 주변 보정
- 높음: 윤곽, 코 성형, 복합 수술 상담 가능성

정확한 금액은 병원, 국가, 재료, 마취 방식, 개인 상태에 따라 달라지므로 결과지에는 "예상 범위"로만 표기한다.

## 9. 추천 로직 설계

추천 로직은 단순히 사용자가 선택한 부위에 대응하는 시술을 바로 매칭하면 안 된다. 다음 순서로 판단한다.

1. 사진 품질 확인
2. 얼굴 비율 및 특징 분석
3. 사용자의 개선 목표 확인
4. 변화 강도 선호 확인
5. 수술/비수술 선호 확인
6. 예산과 회복 가능 기간 확인
7. 개선 방향 카드 생성
8. 카드별 변화 강도 선택
9. 상담 후보 시술 분류
10. 리스크 및 전문의 상담 필요 여부 표시

### 시술 후보 분류

결과지는 시술을 다음처럼 분리한다.

- 메이크업/스타일링으로 가능한 변화
- 피부과/쁘띠 시술 상담 후보
- 성형외과 상담 후보
- 수술적 접근이 필요할 수 있는 항목

이 분류는 사용자가 바로 수술로 향하지 않도록 하고, 고객사 입장에서도 더 신뢰도 높은 상담 퍼널을 만들 수 있다.

## 10. 안전장치

가상 성형 기능에는 반드시 안전장치가 필요하다.

### 필수 고지

- AI 분석은 사진 기준 추정입니다.
- AI 미리보기는 실제 결과를 보장하지 않습니다.
- 실제 가능 여부와 수술/시술 적합성은 전문의 상담이 필요합니다.
- 결과는 개인의 골격, 피부 상태, 회복 과정, 시술 방식에 따라 달라질 수 있습니다.
- 본 서비스는 의료 진단이나 치료 계획을 제공하지 않습니다.

### 분석 제한 조건

다음 경우에는 결과 생성을 제한하거나 상담 우선 안내를 표시한다.

- 사진 품질이 낮은 경우
- 얼굴이 충분히 보이지 않는 경우
- 과도한 변화 요청이 있는 경우
- 미성년자 또는 연령 확인이 필요한 경우
- 건강정보 리스크가 있는 경우
- 사용자가 결과 보장을 기대하는 문구를 입력한 경우

### 표현 금지

- "수술이 필요합니다."
- "반드시 해야 합니다."
- "100% 개선됩니다."
- "정확한 견적입니다."
- "이 얼굴형이 더 예쁩니다."
- "단점입니다."

### 권장 표현

- "상담 후보입니다."
- "사진 기준으로 추정됩니다."
- "이 방향은 사용자의 선택 목표와 잘 맞을 수 있습니다."
- "전문의 상담에서 가능 여부 확인이 필요합니다."
- "참고용 AI 미리보기입니다."

## 11. 개인정보 및 사진 처리 정책

얼굴 사진은 민감도가 높은 데이터이므로 별도 정책이 필요하다.

### 권장 정책

- 분석 목적과 보관 여부를 명확히 고지한다.
- 기본값은 분석 후 즉시 삭제로 둔다.
- 사용자가 결과지 저장을 원할 때만 저장 동의를 받는다.
- 저장 시 보관 기간을 명시한다.
- 사용자가 언제든 삭제 요청할 수 있게 한다.
- 원본 사진과 AI 생성 이미지를 구분해 저장한다.
- 내부 관리자 조회 권한을 최소화한다.

### 저장 데이터 예시

- 사용자 선택값
- 분석 점수
- 개선 방향 카드 정보
- 결과지 요약
- AI 미리보기 이미지 경로
- 동의 여부
- 생성 시간

원본 사진 저장은 기본 기능으로 두지 않는 것을 권장한다. 저장이 꼭 필요하다면 별도 명시 동의를 받아야 한다.

## 12. AI 모델 역할 분담

이 기능은 GPT 모델 하나만으로 처리하거나, RunPod에서 학습한 `.pt` 모델 하나만으로 처리하는 구조가 아니다. 역할을 분리한 하이브리드 구조가 적합하다.

### RunPod `.pt` 모델 또는 CV 모델이 담당할 영역

RunPod에서 만든 기존 `.pt` 모델과 얼굴 분석용 CV 모델은 같은 역할이 아니다. 현재 보유한 `.pt` 모델이 퍼스널컬러 또는 피부케어 분석을 위해 학습된 모델이라면, 얼굴 비율과 대칭을 판단하는 성형 디자인 핵심 모델로 그대로 사용하기는 어렵다.

기존 퍼스널컬러/피부케어 `.pt` 모델은 다음 영역에 제한적으로 재사용한다.

- 피부 톤 분석
- 명도, 채도, 웜/쿨 경향 분석
- 피부결, 잡티, 홍조, 색소, 모공 등 피부 상태 분석
- 결과지의 피부 시술 후보 설명
- AI 미리보기의 피부 보정 강도 참고
- 퍼스널컬러 기반 이미지 톤 보정 참고

다음 영역에는 기존 피부/퍼스널컬러 `.pt` 모델을 핵심 근거로 사용하지 않는다.

- 얼굴 비율 판단
- 턱, 광대, 코, 눈매 개선 후보 판단
- 좌우 대칭 분석
- 얼굴형 기반 성형 방향 추천
- AI 미리보기의 얼굴 구조 변형 위치 계산
- 성형 상담 후보의 핵심 근거 생성

얼굴 구조 분석에는 별도의 랜드마크/CV 모델이 필요하다. MVP에서는 새 `.pt` 모델을 바로 학습하지 않아도 되며, MediaPipe Face Mesh, InsightFace, OpenCV, face-alignment 같은 기존 얼굴 랜드마크 모델을 활용해 시작할 수 있다.

얼굴 분석용 CV 모델은 사진을 보고 다음 정량적 특징을 추출하는 역할을 맡는다.

- 사진 품질 판정 보조
- 얼굴 랜드마크 탐지
- 얼굴형 또는 얼굴 외곽 특징 분석
- 상안부, 중안부, 하안부 비율 계산 보조
- 좌우 대칭 정도 분석
- 턱선, 광대, 코-입-턱 라인 특징 추출
- 피부결, 잡티, 톤 균일도 등 이미지 기반 분석
- 개선 후보 부위 판단에 필요한 feature 생성

즉 현재 보유한 피부/퍼스널컬러 `.pt` 모델은 피부와 톤 분석에 재사용하고, 성형 디자인의 핵심인 얼굴 비율/대칭/윤곽 분석은 별도 랜드마크/CV 모델이 담당해야 한다.

### GPT 모델이 담당할 영역

GPT 모델은 사진 자체를 직접 판단하는 주체가 아니라, CV 분석 결과와 사용자 선택값을 종합해 설명과 리포트를 만드는 역할을 맡는다.

- 사용자 선택값 해석
- 분석 결과를 자연어로 설명
- 개선 방향 카드 3~5개 생성
- 카드별 어울리는 이유 작성
- 상담 후보 시술 분류
- 비수술/수술 상담 후보 구분
- 비용 범위와 회복 기간 범위 설명
- 리스크 및 주의사항 문구 생성
- 병원 상담 시 질문 리스트 생성
- 결과지 문장 생성
- 의료적으로 단정하지 않도록 표현 조절

즉 GPT는 "분석 결과를 상담용 언어와 추천 카드로 정리하는 역할"이다.

### 이미지 생성/편집 모델이 담당할 영역

AI 미리보기 이미지는 기존 GPT 텍스트 모델이나 얼굴 분석 `.pt` 모델만으로는 충분하지 않다. 별도의 이미지 생성 또는 이미지 편집 모델이 필요하다.

후보 구조:

- 외부 이미지 생성/편집 API
- diffusion 기반 face editing 모델
- RunPod에 별도 이미지 생성 서버 구성
- 기존 사진을 보존하면서 특정 부위만 약하게 변형하는 face retouch/editing 파이프라인

이 영역은 "실제 수술 결과 예측"이 아니라 "상담 전 참고용 시뮬레이션 이미지 생성"으로 제한한다.

### 권장 처리 흐름

```text
사용자 입력 + 얼굴 사진
  ↓
기존 RunPod .pt 모델
  - 피부 톤
  - 피부결
  - 잡티/홍조/색소
  - 퍼스널컬러 참고 정보
  ↓
얼굴 랜드마크 / CV 모델
  - 얼굴형
  - 얼굴 비율
  - 좌우 대칭
  - 턱선/광대/코-입-턱 라인
  - 변화 후보 feature
  ↓
GPT 모델
  - 개선 방향 카드 생성
  - 상담 후보 시술 정리
  - 주의사항 작성
  - 결과지 문장 생성
  ↓
이미지 생성/편집 모델
  - AI 미리보기 3~5장 생성
  ↓
상담용 결과지 출력
```

### MVP 적용 기준

MVP에서는 이미지 생성 모델까지 처음부터 완성하지 않아도 된다. 우선순위는 다음과 같다.

1. 기존 RunPod `.pt` 모델은 피부/톤 분석에 재사용
2. 얼굴 비율/대칭은 MediaPipe Face Mesh 등 랜드마크/CV 모델로 별도 분석
3. GPT 기반 개선 방향 카드와 상담용 리포트 생성
4. 이후 이미지 생성/편집 모델을 붙여 AI 미리보기 고도화

초기 버전에서 이미지 미리보기가 어렵다면, 분석 결과와 개선 방향 카드, 상담용 리포트만 먼저 제공하고 이미지 미리보기는 2차 기능으로 분리할 수 있다.

## 13. MVP 범위

초기 버전은 기능을 과도하게 넓히지 않고, 상담 전 참고용 리포트 생성에 집중한다.

### MVP에 포함

- 기본정보 및 목표 설정
- 개선 부위 복수 선택
- 원하는 변화 이미지 복수 선택
- 정면 사진 1장 업로드
- 사진 품질 확인
- 얼굴 비율 분석
- 개선 방향 카드 3개 생성
- AI 미리보기 3개 생성
- 카드별 변화 강도 3단계 선택
- 상담용 결과지 화면 출력

### MVP에서 제외 또는 2차

- 정확한 병원 견적
- 실제 병원별 시술 메뉴 매칭
- 측면/45도 복수 사진 기반 정밀 분석
- 부위별 비율조정 슬라이더
- 병원 예약 연동
- 의사용 코멘트 입력
- PDF 다운로드
- 결과 히스토리 저장
- 국가/지역별 비용 DB

## 14. 2차 고도화 방향

2차 버전에서는 병원 상담 연결과 리포트 품질을 강화한다.

- 정면, 45도, 측면 사진 분석
- 얼굴 랜드마크 기반 상세 비율 점수
- 병원별 시술 메뉴 DB 연동
- 지역/국가별 비용 범위 DB
- 상담 예약 CTA
- 결과지 PDF 다운로드
- 사용자의 선택 카드 히스토리
- 의사 또는 상담사가 코멘트를 추가하는 관리자 화면
- 동일 사용자 전후 비교 관리

## 15. 화면별 핵심 UI

### Step 1: 기본정보 및 목표 설정

- 좌측: 입력 폼
- 우측: 분석 기준 안내
- 하단: 동의 체크 후 다음 버튼 활성화

### Step 2: 사진 업로드 및 품질 확인

- 업로드 영역
- 촬영 가이드
- 품질 체크 결과
- 재촬영 안내

### Step 3: 얼굴 비율 분석

- 얼굴 비율 요약
- 개선 우선순위
- 분석 신뢰도
- 사진 품질 경고

### Step 4: 개선 방향 선택

- 3~5개 카드
- 각 카드의 목표 인상, 변화 강도, 주요 부위
- Before/Preview 썸네일

### Step 5: 상담용 리포트

- 최종 Before/Preview
- 분석 요약
- 개선 우선순위
- 상담 후보 시술
- 예상 비용/회복 기간 범위
- 주의사항
- 상담 질문 리스트

## 16. 상담 질문 리스트 예시

결과지에 아래 질문을 자동 포함하면 사용자가 실제 상담에서 더 안전하게 의사결정을 할 수 있다.

- 제 얼굴 구조에서 이 변화가 실제로 가능한가요?
- 비수술 옵션으로 가능한 범위는 어디까지인가요?
- 수술이 필요하다면 대체 방법은 무엇인가요?
- 예상 회복 기간은 어느 정도인가요?
- 부작용이나 비대칭 가능성은 어느 정도인가요?
- 제 피부 상태나 기존 시술 이력이 결과에 영향을 주나요?
- 결과가 마음에 들지 않을 때 수정 가능성은 어떻게 되나요?
- 비용에 포함되는 항목과 추가 비용은 무엇인가요?

## 17. 참고 기준
