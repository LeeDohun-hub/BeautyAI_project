작성 2026-07-27 · 실행 위치: **AI-Hub 다운로드가 가능한 원격 PC**(VSCode + Claude Code) · 산출물을 로컬로 회수

> **목적**: AI-Hub 04 "네일 및 페디큐어" 데이터셋에서 **네일 디자인 트랙만** 선별 다운로드 → 압축 해제 → 검사 리포트 생성. (손발포즈×피부톤 트랙은 수십~수백GB라 **받지 않음**.) 리포트를 로컬로 가져오면 후속 파이프라인/모델을 설계한다. 관련 설계: `docs/nail_design_feature_design.md`.

## 2. 다운로드 (AI-Hub aihubshell)

```bash
# aihubshell 설치 (리눅스/원격 기준)
curl -o aihubshell -L "https://api.aihub.or.kr/api/aihubshell.do"
chmod +x aihubshell
./aihubshell -help          # ⚠️ 플래그가 버전마다 다름 — 반드시 -help 로 현재 사용법 확인

# 인증(마이페이지 API키) 후, datasetkey + filekey 로 선택 다운로드.
# 예시(현재 문법에 맞게 조정): 여러 키는 콤마로.
./aihubshell -mode d -datasetkey <DATASETKEY> -filekey 572267,572268,572291 -aihubapikey <APIKEY>
```

- 다운로드된 zip을 위 표의 **저장 위치**로 옮긴다(구조 유지). 사실 `inspect` 는 04 루트 아래 어디에 있든 `rglob` 로 찾으므로, 최소한 `data/04.네일 및 페디큐어 데이터/` 아래에만 두면 된다.
- 검증: `ls -la` 로 파일 크기가 표의 값과 일치하는지 확인(0바이트면 실패 — 인증/승인/키 재확인).

## 3. 전처리 = 검사 리포트 생성

```bash
cd <레포루트>/BeautyAI_project
python scripts/inspect_nail_dataset.py            # 디자인 트랙만 검사
#   → 콘솔 출력 + docs/nail_dataset_inspection_report.md 저장
```

이 스크립트는(전체 추출 없이 zip 내부만 읽어) 각 zip의 엔트리 수·확장자·디자인ID 분포·**구조화 라벨(json/csv) 스키마와 택소노미**를 뽑는다. 특히 **메타데이터 zip 안에 디자인 카테고리(범주) 라벨이 있는지**가 핵심 판정 포인트.

## 4. 로컬로 회수할 것 (필수)
1. `docs/nail_dataset_inspection_report.md` (검사 리포트) ← 이거 하나면 후속 설계 가능.
2. 메타데이터 zip 안의 라벨 파일 **1개 샘플**(json/csv면 그 파일). 스키마 직접 확인용.
3. 궁금점: 메타데이터에 카테고리 라벨이 있었는지 / 텍스처 PNG가 마스크인지 패턴크롭인지.

## 5. 다음 단계(로컬, 이번 handoff 이후)
- 리포트에 **범주 라벨이 있으면** → 분류(A안) 파이프라인. 없으면 → 텍스처 리트리벌(B안, 학습 없이 MVP). (설계문서 §1 참조)
- 그때 `scripts/build_nail_design_dataset.py`(매니페스트 빌드)를 전달 → 원격에서 2차 실행.
