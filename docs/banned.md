## 마츠키요(matsukiyococokara) — 포기 (2026-07-01)

메이크업 아이템 매칭에서 마츠키요 버튼/딥링크를 **제거함**. 이유:

1. **공개 상품 API 없음.** 실시간으로 "이 상품이 마츠키요에 있나"를 조회할 수단이 없음.
2. **크롤 데이터가 색조 메이크업이 아님.** `data/manifests/matsukiyo_products.csv`(2,062행)는
   전부 `cat:004`(스킨케어/기초·바디·남성 그루밍) 카테고리. 상위 브랜드가 キュレル·ニベア·
   ギャツビー·ジレット. **메이크업 키워드 포함 3%(72/2062)**이고 그마저 립에센스 등 케어성.
   실제 색조(립/블러셔/아이섀도우/파운데이션)는 인덱스에 사실상 없음 → 로컬 매칭 0%.
3. **검색 링크 검증 불가.** 사이트가 강한 안티봇(HTTP2 fingerprint, ERR_HTTP2_PROTOCOL_ERROR).
   Playwright+실제 Chrome이 아니면 접속 자체가 막힘(curl http=000). 그래서 상품별로
   "검색하면 나오나"를 자동 확인할 방법이 없음. 검색 링크를 붙여도 0건일지 검증 불가.
4. 결론: 색조 메이크업 카테고리 **재크롤 없이는 신뢰할 수 없어** 마츠키요는 드롭.
   (재개하려면: `crawl_matsukiyo.py`로 메이크업 카테고리를 Playwright로 재크롤 → 로컬 인덱스 매칭)

일본(JP)은 **라쿠텐(실시간, 중심) + 아마존JP(검색) + 올리브영 글로벌(K뷰티 한정 검색)**로 운영.
